# Documentation index

This directory contains release, reproducibility, method, and research-design documentation for the RIEC-L1 public package.

## Core public documentation

- `METHOD_OVERVIEW.md` - concise method overview.
- `REPRODUCIBILITY.md` - installation and reproduction notes.
- `DATA_DICTIONARY.md` - public data fields.
- `CONTROLLED_AUDIT.md` - controlled conflict-resolution audit notes.
- `GITHUB_ZENODO_GUIDE.md` - release workflow guide.
- `PUBLIC_RELEASE_CHECKLIST.md` - pre-publication checklist.
- `RELEASE_QA_REPORT.md` - package QA report.

## Methodological notebook

The `research_dossier/` folder is a curated methodological notebook. It records the design reasoning, statistical objects, mathematical boundaries, algorithm decisions, experiment structure, evidence boundaries, and future extensions behind RIEC-L1. It is not editorial correspondence and does not include reviewer responses, cover letters, marked manuscripts, or private notes.

Start here: `research_dossier/00_readme_research_dossier.md`.
